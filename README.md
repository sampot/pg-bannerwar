# 旌旗戰棋 (`pg-bannerwar`)

三章回合制戰棋。地形擋路、兵種相剋、陣亡的弟兄不會回來。

類型：**回合戰棋／SRPG** · 系列：策略

## 玩法

- **點單位 → 藍格是可走範圍 → 點格子移動 → 攻擊或待命。** 移動後還沒攻擊前可以取消。
- **兵種相剋：** 槍剋騎、騎剋弓、弓剋槍。相剋 ×1.5、被剋 ×0.7。
- **地形：** 草埔 +5%、竹林 +20%、土丘 +30% 防禦；溪水與石垣不可通行，可用來卡位。
- **反擊：** 被打的一方若射程夠得到就會反擊。弓兵站兩格外打近戰單位不會挨反擊。
- **成長與陣亡：** 命中與擊殺累積經驗，滿 100 升級（+3 血上限、+1 攻擊）。陣亡的我軍**不會**出現在後續章節。

三章目標依序為殲滅敵軍、十二回合內奪下對岸帥旗、斬落敵方主將。

## 遊玩

純 HTML／CSS／JavaScript，無 build 步驟。本機開 `index.html`，或經 Playgrounds／go 安裝。分數與戰役進度透過 `/api/kv/` 由宿主保存。

## 開發

```bash
npx vitest run
```

`game.js` 是無 DOM 的純邏輯（地圖、移動、戰鬥、目標判定、敵方 AI），`app.js` 只負責 canvas 繪製與輸入。
